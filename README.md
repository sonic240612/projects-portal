## 기능

- **카테고리 탭** — All / Playground / Tools / Lab / Life로 프로젝트 분류
- **정렬** — Newest / Oldest 버튼으로 최신순·오래된 순 정렬
- **Simple 테마** — Light / Dark 모드 전환 지원
- **Animated 테마** — 파티클 효과와 함께하는 다크 스타일
- 테마·카테고리·정렬 상태는 `localStorage`에 저장되어 유지됨
