# Project icons

Liquid Glass 카드 전용 SVG 아이콘입니다. Animated·Simple 디자인에서는 표시하지 않습니다.

## 기존 브랜드

- `lodex.svg`: Lodex 저장소 `apps/desktop/app-icon.svg` 원본을 수정 없이 복사. 짙은 배경, 연두색 L과 점 형태를 유지합니다.
- `hand-in-hand.svg`: hand-in-hand 저장소 `public/index.html`의 `brand-mark`(↔)와 `public/style.css`의 초록색·-27도 회전을 바탕으로 벡터화. 별도 원본 이미지 파일은 없으며, 밝은 앱 타일 배경만 추가했습니다.

## 포털용으로 제작한 아이콘

| 파일 | 모티프 |
| --- | --- |
| `if.svg` | 대화 말풍선과 이야기의 반짝임 |
| `mars-panic.svg` | 붉은 행성과 경고 신호 |
| `focus-forest.svg` | 나무와 집중 타이머 |
| `whereto.svg` | 지도 핀과 이동 경로 |
| `pixel-circle.svg` | 사각 픽셀로 구성한 원 |
| `zen-pebble.svg` | 균형 잡힌 돌 쌓기 |
| `hue-world.svg` | 지구본과 다채로운 무드 |
| `tikatuka.svg` | 두 개의 주사위 |
| `ladder.svg` | 사다리 타기의 선택 경로 |
| `open-survivor.svg` | 생존을 상징하는 방패와 픽셀 투구 |

새 아이콘은 128×128 viewBox의 벡터로 제작했습니다. 외부 폰트·이미지·스크립트에 의존하지 않으며, 각 파일을 독립적으로 사용할 수 있습니다. 색상과 카드 연결은 `index.html`의 `artwork` 설정에서 관리합니다.
